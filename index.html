How it works

The director front agent splits your script into scenes. The caster picks the animation library per scene (Anime.js, Motion Canvas, Manim, Three.js or Proton) through a grounded site action. The matching writer renders the scene. The exporter returns the storyboard JSON. With your consent, the critic peer network — loaded by URL, run in your browser, on your key — reviews the storyboard and returns a verdict.

Read the agent network definition

The network is public data, not code: director.network.json lists the agents, their instructions and the tools each may call. Any conforming runtime can run it.
